# Strong Boxing ERP Starter

멀티 지점 복싱/체육관 ERP 스타터 웹앱입니다.

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 열기:

```text
http://localhost:3000
```

## 포함된 화면

- `/login` 로그인
- `/dashboard` 관리자 대시보드
- `/members` 회원관리
- `/payments` 결제관리
- `/crm` 상담 CRM
- `/staff` 직원/스케줄
- `/finance` 재무
- `/mobile-owner` 대표 모바일 화면
- `/check-in` 체크인 키오스크
